# بوت تلغرام لتحويل الملفات إلى Markdown

بوت مستقل يحوّل ملفات **PDF / DOCX / PPTX / XLSX / TXT / MD / CSV / HTML / PNG / JPG / WEBP** إلى `.md` ويعيد الملف في تيليجرام. لا يستدعي واجهة API للذكاء الاصطناعي أثناء التحويل.

## طريقة الاستخدام

1. افتح [@BotFather](https://t.me/BotFather) على تيليجرام، وأرسل `/newbot` ثم اتبع التعليمات. احتفظ **بالتوكن** سرًا.
2. شغّل البوت على جهازك أو انشره باستضافة (التعليمات أسفل).
3. في تيليجرام ارسل `/start` للبوت، ثم أرسل ملفًا أو صورة.
4. استلم ملف `.md` بالنص والجداول المستخرجة.
5. `/mode` لاختيار **دقيق** (المحتوى الخام مع تنسيق Markdown) أو **موفر** (تنظيف الزوائد الشكلية، دون حذف الفقرات).
6. `/ocr on` يفرض OCR على ملفات PDF لو كان استخراج الأحرف خاطئًا. `/ocr off` يرجع للتلقائي.

**مهم:** لا يعني التحويل إلى Markdown دائمًا انخفاض عدد التوكنز. يحسب البوت تقديرًا للتوكنز قبل التنظيف وبعده، وليس مقارنة حقيقية مع إرسال الملف الأصلي إلى أي نموذج رؤية. الصور والرسوم والمعادلات قد تحتاج مراجعة يدوية. OCR عربي/إنجليزي متاح بعد تثبيت Tesseract.

## تشغيل على Windows

ثبّت Python 3.12، ثم افتح PowerShell داخل المجلد:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:BOT_TOKEN="PUT_YOUR_TOKEN_HERE"
python bot.py
```

لـOCR: ثبّت Tesseract OCR، وتأكّد من ملفات اللغتين `ara` و`eng` وأن `tesseract.exe` في PATH. بدون Tesseract، يمكن تحويل ملفات PDF النصية وملفات Office، لكن استخراج الصور لن يعمل.

## نشر البوت على Render

هذه الطريقة تستخدم **Webhook**، وليس polling، حتى يعمل البوت مع خدمات الويب.

1. ارفع ملفات المشروع إلى مستودع GitHub **بدون ملف `.env` وبدون التوكن**.
2. افتح Render واختر **New → Blueprint** ثم اربط المستودع المحتوي على `render.yaml`، أو **New → Web Service** واجعل Runtime = Docker وPlan = Free.
3. أضف في Environment **`BOT_TOKEN` فقط** = رمز البوت من BotFather. عند استعمال Blueprint يطلب Render إدخاله بأمان.
4. احفظ المتغيرات ثم **Deploy**؛ يستخرج البرنامج رابط `RENDER_EXTERNAL_HOSTNAME` تلقائيًا، وينشئ رمز تحقق خاصًا بالـWebhook من توكن البوت دون عرضه في السجلات.
5. أرسل `/start` إلى البوت لاختبار الاستجابة.

إذا استخدمت استضافة مختلفة عن Render، عيّن `WEBHOOK_BASE_URL` بالرابط الخارجي HTTPS وأضف `WEBHOOK_SECRET` اختياريًا. محليًا اترك هذين المتغيرين فارغين.

**محدودية خطة Render Free:** قد تنام الخدمة بعد 15 دقيقة من عدم ورود طلبات، فتكون أول استجابة بطيئة نحو دقيقة، ومن الممكن أن تتوقف المعالجة بسبب حدود الموارد المجانية. الملفات لا تُخزّن دائمًا؛ يستخدم البرنامج ملفات مؤقتة ويزيلها بعد المعالجة. وجود بوت على خادم طرف ثالث يعني أن الملف يمر عبر تيليجرام والخادم، لذا لا ترسل ملفات سرية إلى استضافة لا تثق بها.

## حدود النسخة

- الحد الافتراضي للتحميل 15 ميجابايت (وحد تنزيل البوت في Telegram Bot API هو 20 ميجابايت).
- حد صفحات PDF: 40 صفحة؛ OCR لعدد صفحات كبير قد يكون بطيئًا.
- دعم الملفات القديمة `.doc` و`.ppt` و`.xls` غير موجود؛ حوّلها أولًا إلى الصيغ الحديثة.
- قراءة المعادلات الرياضية الدقيقة والتخطيطات العربية المعقدة ليست مضمونة؛ يمكن تجربة `/ocr on` لتحسين الملف ذي الطبقة النصية الفاسدة.
- تحويل الجداول يحاول الاحتفاظ بالخلايا، لكن تنسيقات الألوان والرسومات والصور لا تتحول تلقائيًا إلى نص.
- لا توجد حسابات ولا قاعدة بيانات ولا نسخ دائمة للملفات. يعتمد اختيار الوضع على ذاكرة التشغيل ويعود إلى الدقيق بعد إعادة تشغيل الخدمة.

## بنية الملفات

- `bot.py` يستقبل ويرد على ملفات تيليجرام.
- `converter.py` لتحويل الملفات وتنظيف النص وحساب تقدير التوكنز.
- `Dockerfile` يتولى تثبيت Tesseract العربي والإنجليزي.
- `render.yaml` خيار نشر مجاني مبدئي.
- `tests/` اختبارات لوظائف التحويل.
